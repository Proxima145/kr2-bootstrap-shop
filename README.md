# Слой

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

Тема — «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Учебный магазин керамики с каталогом, карточкой изделия и формой заявки. Озеров Максим Дмитриевич, группа ЭФБО-11-25.

## Практическое занятие №9

На главной есть шапка, вводный блок, преимущества, популярные товары и подвал. Сетка собрана классами `container`, `container-fluid`, `row`, `col-12`, `col-md-6`, `col-lg-4` и `g-*`.

Bootstrap 5.3.8 CSS и JS Bundle подключены через CDN. После стилей Bootstrap подключён `css/custom.css`.

Открой `index.html`. Проверь, что сетка популярных товаров занимает одну, две и три колонки на маленьком, среднем и большом экране.
