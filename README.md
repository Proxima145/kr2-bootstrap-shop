# Слой

Контрольная работа №2 по дисциплине «Фронтенд и бэкенд разработка».

Тема — «CSS-фреймворки: разработка интерфейса на Bootstrap или альтернативном CSS-фреймворке».

Учебный магазин керамики с каталогом, карточкой изделия и формой заявки. Озеров Максим Дмитриевич, группа ЭФБО-11-25.

[Открыть сайт на GitHub Pages](https://proxima145.github.io/kr2-bootstrap-shop/)

## Подключение Bootstrap

Bootstrap 5.3.8 подключён локально. Стили находятся в `vendor/bootstrap/css/bootstrap.min.css`, а JS Bundle в `vendor/bootstrap/js/bootstrap.bundle.min.js`. После Bootstrap загружается `css/custom.css` с цветами и стилями магазина. Открой `index.html` в браузере. Для просмотра скачанного проекта достаточно файлов репозитория.

## Структура

| Файл или папка | Содержимое |
| --- | --- |
| `index.html` | Главная, преимущества, популярные изделия |
| `catalog.html` | Каталог с карточками и фильтром |
| `product.html` | Изделия, цены, таблицы характеристик и окно доставки |
| `order.html` | Заявка с префиксом +7, выбором изделия и проверкой полей |
| `contacts.html` | Контакты мастерской и раскрывающиеся ответы |
| `css/custom.css` | Фирменные цвета и стили магазина |
| `js/shop.js` | Открытие выбранной карточки и выбор изделия в заявке |
| `images/` | Фото изделий |
| `vendor/bootstrap/` | Bootstrap CSS, JS Bundle и лицензия |
| `.gitignore` | Исключения для системных файлов и файлов редактора |

## Компоненты

- Сетка на `container`, `container-fluid`, `row`, `col-12`, `col-md-*`, `col-lg-*` и отступах `g-*`.
- Навигация `navbar` с раскрывающимся меню, карточки `card`, кнопки `btn-primary` и `btn-outline-primary`, метки `badge`.
- Сообщения `alert`, окно доставки `modal`, таблицы `table`, хлебные крошки `breadcrumb` и ответы `accordion`.
- Форма с `form-control`, `form-select`, `input-group` и `form-check`.

## Доработки

- Фильтр по трём категориям на радиокнопках и CSS. У каждого из шести изделий есть своя ссылка на карточку.
- При переходе из карточки форма сразу выбирает нужное изделие. Телефон вводится как 10 цифр после +7. После проверки полей появляется сообщение. Тестовые данные остаются в браузере.
- Страница контактов с раскрывающимися ответами об уходе и упаковке.

## Проверка

1. На главной открой меню на узком экране и перейди в каталог. Проверь одну, две и три колонки карточек на разных ширинах.
2. Выбери категорию, открой карточку изделия и окно доставки. Закрой его крестиком или клавишей Esc.
3. Перейди из карточки к заявке. Проверь выбор изделия, обязательные поля, почту, телефон и сообщение после отправки тестовой формы.
4. На странице контактов раскрой один ответ, затем другой. Первый должен свернуться.
